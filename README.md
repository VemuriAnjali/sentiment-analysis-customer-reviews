# Sentiment Analysis on Customer Reviews

**Capstone project** by Vemuri Anjali  
SRK Institute of Technology — Computer Science and Engineering (Data Science)

## Overview

This project focuses on classifying restaurant/customer reviews as **positive** or **negative** using natural language processing (NLP) and machine learning. The project presentation describes a workflow covering data collection, text preprocessing, model training, evaluation, and potential deployment.

## Project files

- `sentiment_analysis.ipynb` — Jupyter Notebook containing the project code.
- `project_presentation.pptx` — Capstone project presentation.

## Technologies mentioned in the presentation

- Python / Jupyter Notebook / Anaconda
- pandas
- matplotlib
- seaborn
- scikit-learn
- NLP text preprocessing techniques such as lowercasing, tokenization, cleaning, and lemmatization
- Naive Bayes is discussed as a candidate classification algorithm in the presentation.

> Note: The exact algorithm, dataset, and evaluation metrics used should be confirmed from the notebook's executed code and outputs. The presentation describes the intended approach and mentions precision, recall, and F1 score as evaluation metrics.

## How to open

1. Download or clone this repository.
2. Open `sentiment_analysis.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install any Python libraries imported by the notebook if they are not already available.
4. Follow the notebook cells in order. If the notebook expects a dataset file, place that dataset at the path referenced in the code.

## Project goal

Analyze review text and predict whether the expressed sentiment is positive or negative, helping summarize customer feedback.
